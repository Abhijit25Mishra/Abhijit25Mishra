## What I do

- **Backend engineering (~2.5 yrs, production):** REST APIs, microservices with the **Backend-for-Frontend (BFF)** pattern, layered service/repository architecture, role-based access control (RBAC), third-party integrations (Google Maps & Places, CRM systems)
- **Geospatial systems:** polygon computation and unions (Turf.js), MongoDB **geo-indexes & `$geoNear` aggregations**, viewport-based filtering, location-hierarchy modeling with cycle detection
- **Multi-market / multi-tenant architecture:** country-scoped data isolation at the query layer, request-scoped context via **AsyncLocalStorage**, currency & locale handling
- **Performance & scale:** aggregation-pipeline optimization, **N+1 query elimination** with batch lookups, indexing strategy, idempotent backfills over tens of millions of documents, rate-limited batch jobs against external APIs
- **Reliability & observability:** structured logging, **Sentry** error tracking, correlation IDs, AWS CloudWatch, message queues (**BullMQ / Redis**), defensive error classification
